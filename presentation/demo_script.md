# SpectraPlan five-minute demonstration

Target time: 4:45. Use a novel development enquiry or a clearly labelled prior run if the live provider is unavailable.

| Time | Action | Spoken point |
|---|---|---|
| 0:00–0:45 | Paste the enquiry and submit | The app preserves the customer's wording and separates stated facts from unknowns. |
| 0:45–1:30 | Read requirements and questions | Questions are tied to an engineering decision, such as geometry, matrix or validation. |
| 1:30–2:30 | Open a recommendation citation | The method is conditional and the evidence drawer shows the reviewed AFS passage and page. |
| 2:30–3:30 | Show risks and the experiment | The output proposes samples, reference assays, independent validation and a customer decision basis. |
| 3:30–4:20 | Answer one clarification, reopen the enquiry and select the new round | History links the round to the original enquiry and keeps the answer provenance visible. |
| 4:20–4:45 | Export JSON and, if time allows, the chemist or trace PDF | The selected run, evidence and metadata stay together; a trace export includes enquiry, source and model content. |

Then show the contrasting uncertainty case: an enquiry with an undefined contaminant or unsupported proxy. Point out the `insufficient_information` or conditional result and the next information request.

If the live provider is slow, switch to a saved output from `outputs/development/` and say “prior run” before showing it. Do not present saved output as a new live result. Keep the final evaluation cases out of the demonstration.

Limit claims to observed behavior. The app provides a first technical assessment and a proposed experiment; it does not prove spectroscopy accuracy, probe compatibility or clinical readiness.
